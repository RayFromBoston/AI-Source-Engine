THE FIX

AL-1.0

A practical, open-source attribution layer that reuses the attention the model already computes.

<1% extra compute
Works on existing transformer architectures
Produces auditable mathematical receipts
How it works (plain English)
  1. 01 During training, every token gets a source_idx tag.
  2. 02 At generation time we read the attention weights the model already calculates.
  3. 03 We bucket those weights by source and normalize them into a receipt.
  4. 04 The output now shows exactly which sources influenced the answer and by how much.
